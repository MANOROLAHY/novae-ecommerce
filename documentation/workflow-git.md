# Workflow Git - Projet NOVAÉ

## Branches

- main : version stable du projet.
- develop : intégration et validation des modifications.
- feature/* : développement de nouvelles fonctionnalités.

## Cycle de développement

1. Créer une branche feature depuis develop.
2. Développer et tester les modifications.
3. Créer un commit.
4. Pousser la branche feature sur GitHub.
5. Ouvrir une Pull Request vers develop.
6. Vérifier les tests GitHub Actions.
7. Fusionner après validation.
